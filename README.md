# 🎵 Spotify Clone

A simple **Spotify-inspired music player** built with **HTML, CSS, and JavaScript**. This project recreates the look and feel of Spotify’s player UI with a **dark theme, responsive design**, and fully functional **audio playback controls** – all without requiring login or signup.

---

## 🚀 Features

* 🎨 **Spotify-like UI**: Dark theme layout with a navbar, sidebar, cards for songs, and a sticky bottom playbar.
* ▶️ **Music Playback**: Play, Pause, Next, and Previous track functionality using the HTML5 `<audio>` API.
* 🔊 **Volume Control**: Adjustable volume slider and a mute/unmute toggle button.
* 📂 **Dynamic Song List**: Local MP3 files are fetched and displayed automatically.
* 📱 **Responsive Design**: Works smoothly across desktop, tablet, and mobile devices.
* ⚡ **No Authentication Needed**: Instantly usable without login/signup.

---

## 🛠️ Tech Stack

* **HTML5** – Structure and semantic layout.
* **CSS3** – Custom styling, responsive grid system, dark theme, and utility classes (`style.css` + `utility.css`).
* **JavaScript (Vanilla JS)** – Audio player logic, DOM event handling, and interactivity.

---

## 📂 Project Structure

```
Spotify_Clone/
│── index.html        # Main entry point
│── style.css         # Core styles (dark theme, layout, playbar, cards)
│── utility.css       # Utility classes for spacing, flex, grid, text, etc.
│── javascript.js     # Audio player logic and UI interactions
│── /songs            # Folder containing local MP3 files
│── /img              # Icons (play, pause, volume, mute, etc.)
```

## 🎧 How to Use

1. **Clone the repository**:

   ```bash
   git clone https://github.com/ChiragVasava/Spotify_Clonne.git
   cd Spotify_Clonne
   ```

2. **Open `index.html`** in your browser directly, or use a live server:

   ```bash
   npx live-server
   ```

   > (Or use VS Code’s **Live Preview** / **Live Server** extension.)

3. 🎶 **Enjoy the music**!

   * Use the **Play/Pause** button to control playback.
   * Switch tracks using **Next/Previous** buttons.
   * Adjust audio with the **volume slider** or **mute/unmute** icon.
